\subsection{Agent-Based Modelling and Multi-Agent Systems}

Agent-based modelling is a powerful tool for studying complex systems by simulating the behaviors of autonomous individuals \citep{ar:Macal2016,ar:GallegatiEtAl2024}. This approach allows macro-level phenomena to emerge from simple micro-level rules. A classic example is Reynolds' boids model where agents follow basic steering rules like separation and alignment to produce coherent flocking patterns \citep{inpr:Reynolds1987}. In the context of search and rescue, this framework helps us see how agent-level choices translate into collective search efficiency.

\subsection{Belief-Desire-Intention Architecture}

We implement a BDI architecture to define our agents. In this model, beliefs represent what the agent knows about the world through its sensors. Desires are the objectives the agent wants to achieve such as covering the search area. Intentions are the specific plans the agent commits to like exploring or returning to charge \citep{bk:Wooldridge2009}. We encode this logic directly into hierarchical statecharts where every belief update and intention switch is a named transition. This ensures the reasoning process of each agent is visible.

\subsection{Ant Colony Optimization and Stigmergy}

Coordination is achieved through stigmergy where agents communicate by modifying their shared environment \citep{bk:Bonabeau1999}. Standard Ant Colony Optimization uses pheromones as a positive signal to attract agents to successful paths \citep{bk:Dorigo2004}. We reverse this logic for search missions. In our system, pheromone acts as a redundancy signal that repels agents from recently searched areas. This inversion preserves the mathematical benefits of ACO while creating a dispersion mechanism that prevents agents from duplicating effort. The result is a system that naturally spreads the fleet across the environment.
